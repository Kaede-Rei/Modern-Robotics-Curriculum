# 机器人传感器基础：机器人究竟测到了什么

> **问题：** 一台机器人同时装有深度相机、IMU、激光雷达、轮编码器和六维力传感器，就一定知道自己的位置、速度、接触力和目标姿态吗？**传感器原始读数不是状态真值**；每种测量只约束部分未知量，还受时钟、坐标系和误差模型制约

**先修：** F04 概率、F05 坐标系；**学习目标：**区分被测量、物理状态、可观测性与常见误差；能写出最小测量方程

## 1. 一个统一的测量观点

设希望估计的状态为 $\mathbf x$，标定参数为 $\boldsymbol\theta$，测量 $\mathbf z$ 满足

$$
\boxed{\mathbf z=h(\mathbf x,\boldsymbol\theta)+\mathbf n}
$$

$h$ 描述传感器的几何/物理过程，$\mathbf n$ 是在适当条件下采用的测量噪声模型；**传感器偏置、失配、遮挡、饱和与异常值不能随意全视为零均值高斯白噪声；** 若 $h$ 对某个状态方向不敏感，仅加传感器频率或滤波器复杂度不能凭空恢复该方向

| 传感器 | 直接观测的量 | 常见不可忽视问题 |
|---|---|---|
| 单目相机 | 像素亮度/颜色和成像几何 | 绝对尺度不直接给出，光照和运动模糊 |
| 双目/RGB-D | 视差或估计深度、颜色 | 深度范围、无效深度、反光/透射材料、空间对齐 |
| LiDAR | 扫描方向和距离、回波强度等 | 点的采样时间、遮挡、退化几何与动态物体 |
| 加速度计 | **比力** specific force | 重力与线加速度耦合，偏置和振动 |
| 陀螺仪 | 机体系角速度 | 偏置积分漂移、温漂、安装误差 |
| 轮编码器 | 电机/车轮角度和角速度 | 打滑、轮径/传动比误差 |
| 六轴力矩传感器 | 某参考点处的三维力和力矩 | 重力/工具惯性补偿、零点、温度与方向 |
| 触觉阵列 | 接触压力/剪切等空间分布 | 滞后、接触材料差异、空间分辨率 |

## 2. IMU：为什么静止时加速度计不是零

在约定世界重力加速度为 $\mathbf g^w$、$\mathbf R_{wb}$ 将机体系向量映射到世界系时，理想加速度计输出可写为

$$
\mathbf a_m^b=\mathbf R_{wb}^T(\mathbf a^w-\mathbf g^w)+\mathbf b_a+\mathbf n_a
$$

陀螺仪为 $\boldsymbol\omega_m^b=\boldsymbol\omega^b+\mathbf b_g+\mathbf n_g$；静止时 $\mathbf a^w=0$，若机体系与世界系对齐且世界重力竖直向下，则加速度计会报告向上的约 $9.81\,\mathrm{m/s^2}$ 比力；**把这个信号当零并直接积分，会出现巨大的速度位置漂移**

积分还涉及随机游走偏置：同一个陀螺偏置 $b_g$ 在时间 $t$ 内带来约 $b_g t$ 的角度误差，随后通过重力投影污染加速度估计；P03 会讨论如何把偏置并入状态

## 3. 摄像头、雷达和运动畸变

针孔相机的像素与深度关系在 P04 展开；激光雷达每个点的真实观测时刻通常不同；若机器人在一帧内移动，把所有点当作同一时刻可能产生**扫描畸变**；去畸变需要时序、运动估计与外参，不能把外参标定和运动补偿混成一回事

常见时间问题包括硬件同步（触发/PPS）、驱动层时间戳、传输延迟、时钟偏移和时钟漂移；数据包到达时间不一定等于曝光或采样的物理时间

## 4. 进阶：协方差、可观测性和标定

局部线性化 $\mathbf z\approx h(\hat{\mathbf x})+\mathbf H(\mathbf x-\hat{\mathbf x})+\mathbf n$，其中 $\mathbf H=\partial h/\partial\mathbf x$；如果 $\mathbf H$ 的某列方向缺少观测灵敏度，需要其他传感器、运动激励或先验约束；多个测量的完整可观测性还与状态动力学有关，不是仅靠单个 $\mathbf H$ 的秩判断

传感器精度、准确度、分辨率、重复性、采样频率与延迟各自不同；尤其不同厂家标注的距离精度与定位精度不能直接比较

## 5. 实践：设计机器人传感器记录表

| 必须记录 | 目的 |
|---|---|
| 原始数据、原始物理时间戳及时间基准 | 保持可重放性 |
| 坐标系 ID、单位、标定参数标识 | 防止姿态/量纲混用 |
| 有效性、饱和、温度、曝光、诊断状态 | 解释非高斯失败 |
| 同步状态与时差统计 | 评估时间对齐 |
