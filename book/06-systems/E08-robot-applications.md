# 机器人应用专题：从同一组理论走向不同机器

> **问题：** 为什么已经掌握机械臂运动学、PID 和 SLAM，仍不能直接开发能稳定操作、行走或飞行的所有机器人

**先修：** E06、M07、L06；**学习目标：**识别共性机器人模型与领域特有约束，为不同形态和行业选择正确的进一步学习路线

## 核心｜1. 共同骨架与差异所在

绝大多数机器人系统都存在感知、状态估计、任务规划、运动生成、反馈控制与执行器约束；然而各平台的动力学结构、接触模式、可观测状态、失效代价不同

**同一套基础数学可迁移**，但不能把一套固定基六轴机械臂的控制器原封不动用于四足、无人机或水下机器人

| 类别 | 典型任务 | 相比固定基机械臂新增的主要问题 |
|---|---|---|
| 工业操作机器人 | 焊接、装配、码垛 | 工装定位、公差、接触力、节拍与安全单元 |
| 农业机器人 | 采摘、喷施、巡检 | 枝叶遮挡、目标柔顺接触、泥地移动、光照与环境变化 |
| 移动机器人 | 搬运、巡视 | 轮地接触、定位失效、动态障碍与路线管理 |
| 腿足/人形 | 行走、搬运与全身操作 | 浮动基、足底接触、零空间与全身平衡 |
| 空中机器人 | 飞行、检查 | 六自由度姿态、推力约束、气动干扰与故障应急 |
| 水下机器人 | 海底观测、作业 | 浮力、附加质量、阻力、流场与低带宽传感 |
| 医疗机器人 | 手术、康复辅助 | 人体交互、医疗风险和专门的法规认证 |
| 软体/连续体机器人 | 柔性抓取、狭小空间操作 | 连续变形、非线性材料和分布式模型 |
| 微纳与群体机器人 | 微操作、编队协作 | 尺度效应、多主体通信及群体控制 |

## 核心｜2. 从任务反推模型

设计顺序建议是**明确任务与风险 → 识别物理约束与感知限制 → 选择机构与执行器 → 选择可用的数学模型 → 规划与控制 → 实验验证**

例如一台番茄采摘机器人首先需要确认果柄位置和可视性、接触力上限、末端执行器结构、操作空间与定位误差，再决定是否需要精确的逆动力学、视觉伺服或柔顺控制；仅把更复杂的控制器引入系统，并不能自动克服视觉遮挡或末端执行器设计缺陷

## 核心｜3. 工业与农业场景的成功定义

工业机器人常在结构化环境追求节拍、重复定位精度与合规；农业机器人则面临非结构化场景和目标差异；对于采摘或剪切任务，**实际摘下目标且未造成超限损伤**才是任务级成功；机械臂按轨迹结束并不能单独证明这一点

应分别评估定位误差、操作成功率、损伤率、单目标时间、未识别比例、连续作业可靠性及人工干预次数；不同领域的指标不能简单用“成功率”一种数值替代

## 进阶｜4. 浮动基与腿足系统

浮动基机器人比固定基机械臂多了基座位置姿态自由度，且系统控制通常受接触约束与摩擦限制；机器人并非所有自由度都直接受电机驱动，不能直接把固定基逆动力学的 $\tau=M(q)\ddot q+h(q,\dot q)$ 当成全身独立可控加速度映射

全身控制与 MPC 需要处理接触切换、摩擦锥及平衡约束；学习策略的成功也不直接等于无需底层安全和状态估计

## 进阶｜5. 适用标准与环境要求

工业机器人本体与工作站有专门安全标准；医疗、航空与公共服务应用往往处在不同的监管框架内，不能只根据“都是机器人”就套用相同的合规清单；详细范围见 E05

对于共享人类空间、农业户外或半结构化作业系统，应单独识别能见度、天气、地形、人员进入和失联状态等风险

## 实践｜6. 从一个项目生成最小技术清单

选取一个目标任务，例如“视觉导航至温室垄间指定位置并采摘一枚成熟果实”，给出以下最小工程描述

1. 状态与传感器：每项观测的坐标系、时间戳、可测精度与不确定度
2. 机构与执行：底盘、机械臂、末端工具及其控制模式
3. 算法链路：定位、视觉、轨迹规划、接触控制和任务状态监督
4. 安全边界：危险动作许可、超时和恢复
5. 验收证据：目标成功率、损伤率、耗时、异常次数及记录要求

这一练习将本书各篇的知识连接为实际问题定义，而不是一份固定厂商设备清单

### 自测

1. 哪些理论可在移动底盘与机械臂间复用，哪些约束必须重新建模

3. 为什么移动平台与医疗设备的安全标准不可简单互用
